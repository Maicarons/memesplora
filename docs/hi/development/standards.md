# डेवलपमेंट गाइड

## कोड मानक

- **Go**: [Go कोड समीक्षा टिप्पणियाँ](https://go.dev/wiki/CodeReviewComments) का पालन करें
- **TypeScript/React**: ESLint अनुशंसित कॉन्फ़िगरेशन का पालन करें
- Go कोड फ़ॉर्मेटिंग के लिए `gofmt` का उपयोग करें
- फ्रंटएंड कोड फ़ॉर्मेटिंग के लिए `prettier` का उपयोग करें

## कंकरेंसी सुरक्षा

- पढ़ने-भारी परिदृश्यों के लिए `sync.RWMutex` का उपयोग करें
- डेडलॉक को रोकने के लिए हमेशा उसी क्रम में लॉक प्राप्त करें
- लॉक रिलीज़ करने के लिए `defer` का उपयोग करें
- लॉक पकड़ते समय बाहरी इंटरफ़ेस कॉल करने से बचें

## त्रुटि प्रबंधन

```go
type AppError struct {
    Code    int    `json:"code"`
    Message string `json:"message"`
}
```

## परीक्षण

- मुख्य मॉड्यूल के लिए यूनिट टेस्ट कवरेज कम से कम 80% होना चाहिए
- API परत को इंटीग्रेशन टेस्ट की आवश्यकता है
- `testing` मानक पुस्तकालय का उपयोग करें

## CI/CD

प्रोजेक्ट CI/CD के लिए GitHub Actions का उपयोग करता है:

- **बैकएंड CI**: push/PR पर बिल्ड, टेस्ट और वेट
- **फ्रंटएंड CI**: TypeScript जांच और बिल्ड
- **दस्तावेज़ CI**: VitePress बिल्ड और GitHub Pages पर डिप्लॉय

विवरण के लिए [CI/CD कॉन्फ़िगरेशन](/development/ci-cd) देखें।
