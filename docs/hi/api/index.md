# API संदर्भ

Memesplora तीन एक्सेस प्रोटोकॉल प्रदान करता है:

## REST API

फ़ाइल प्रबंधन, स्पेस प्रबंधन, उपयोगकर्ता प्रमाणीकरण और शेयरिंग के लिए पूर्ण HTTP API।

- **पोर्ट**: 5212
- **Base URL**: `http://localhost:5212/api/v3`
- **प्रमाणीकरण**: JWT Bearer Token
- **दस्तावेज़**: [REST API संदर्भ](/api/rest)

## S3-संगत API

rclone, AWS CLI, MinIO Client और अन्य S3 टूल के साथ उपयोग के लिए AWS S3-संगत प्रोटोकॉल।

- **पोर्ट**: 5213
- **प्रमाणीकरण**: AWS Signature V4
- **दस्तावेज़**: [S3 API संदर्भ](/api/s3)

## WebDAV

ऑपरेटिंग सिस्टम फ़ाइल मैनेजर में नेटवर्क ड्राइव के रूप में माउंट करने के लिए WebDAV प्रोटोकॉल।

- **पोर्ट**: 5214
- **प्रमाणीकरण**: HTTP Basic Auth
- **दस्तावेज़**: [WebDAV संदर्भ](/api/webdav)
