# योगदान

## कोड शैली

- **Go**: [Go कोड समीक्षा टिप्पणियाँ](https://go.dev/wiki/CodeReviewComments) का पालन करें
- **TypeScript/React**: ESLint नियमों का पालन करें
- फ़ॉर्मेटिंग के लिए `gofmt` और `prettier` का उपयोग करें

## कमिट संदेश प्रारूप

```
<type>(<scope>): <subject>

<body>
```

प्रकार: `feat`, `fix`, `docs`, `style`, `refactor`, `test`, `chore`

## शाखा रणनीति

- `main`: स्थिर रिलीज़
- `develop`: डेवलपमेंट शाखा
- `feature/*`: फीचर शाखाएं
- `fix/*`: बग फिक्स

## पुल रिक्वेस्ट प्रक्रिया

1. रिपॉजिटरी को फोर्क करें
2. एक फीचर शाखा बनाएं: `git checkout -b feature/your-feature`
3. अपने बदलाव कमिट करें
4. टेस्ट चलाएं: `make test`
5. एक पुल रिक्वेस्ट बनाएं

## कोड समीक्षा

सभी PR को कम से कम एक मेंटेनर समीक्षा की आवश्यकता है। ध्यान केंद्रित क्षेत्र:
- मेमोरी सुरक्षा
- कंकरेंसी सुरक्षा (लॉक सहीता)
- त्रुटि प्रबंधन पूर्णता
- API संगतता
