## पोर्ट मैप

| पोर्ट | सेवा | विवरण |
|:----:|---------|-------------|
| 5212 | REST API + Web UI | HTTP API और फ्रंटएंड के लिए मुख्य पोर्ट |
| 5213 | S3 API | AWS S3-संगत प्रोटोकॉल |
| 5214 | WebDAV | WebDAV प्रोटोकॉल |

## तकनीकी स्टैक

| परत | तकनीक |
|-------|-----------|
| बैकएंड | Go 1.22+, Gin, ent, golang.org/x/net/webdav |
| फ्रंटएंड | React 18, TypeScript, Ant Design 5, Zustand, Vite |
| डेटाबेस | SQLite / PostgreSQL (केवल मेटाडेटा) |
| RAM | mmap (Linux/macOS) / VirtualAlloc (Windows) |
| VRAM | CUDA + NVML (स्टब, एकीकरण के लिए तैयार) |
