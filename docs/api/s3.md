# S3 Compatible API Reference

## Overview

Memesplora provides an AWS S3-compatible API for use with any S3-compatible client.

## Endpoint

`http://localhost:5213`

## Supported Operations

### Bucket
- `GET /` - ListBuckets
- `HEAD /{bucket}` - HeadBucket

### Objects
- `GET /{bucket}/{key}` - GetObject
- `PUT /{bucket}/{key}` - PutObject
- `DELETE /{bucket}/{key}` - DeleteObject
- `HEAD /{bucket}/{key}` - HeadObject
- `GET /{bucket}` - ListObjects / ListObjectsV2
- `POST /{bucket}?delete` - DeleteObjects

### Multipart Uploads
- `POST /{bucket}/{key}?uploads` - CreateMultipartUpload
- `PUT /{bucket}/{key}?partNumber=&uploadId=` - UploadPart
- `POST /{bucket}/{key}?uploadId=` - CompleteMultipartUpload
- `DELETE /{bucket}/{key}?uploadId=` - AbortMultipartUpload
- `GET /{bucket}/{key}?uploadId=` - ListParts

## Examples

### AWS CLI
```bash
aws configure --profile memesplora
aws s3 --endpoint-url http://localhost:5213 ls
```

### rclone
```bash
rclone config  # Select S3 Compatible
rclone copy file.txt memesplora:my-space/
```
