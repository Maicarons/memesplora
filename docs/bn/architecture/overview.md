## পোর্ট ম্যাপ

| পোর্ট | সার্ভিস | বিবরণ |
|:----:|---------|-------------|
| 5212 | REST API + Web UI | HTTP API এবং ফ্রন্টএন্ডের জন্য প্রধান পোর্ট |
| 5213 | S3 API | AWS S3-সামঞ্জস্যপূর্ণ প্রোটোকল |
| 5214 | WebDAV | WebDAV প্রোটোকল |

## টেক স্ট্যাক

| লেয়ার | প্রযুক্তি |
|-------|-----------|
| ব্যাকএন্ড | Go 1.22+, Gin, ent, golang.org/x/net/webdav |
| ফ্রন্টএন্ড | React 18, TypeScript, Ant Design 5, Zustand, Vite |
| ডাটাবেস | SQLite / PostgreSQL (শুধুমাত্র মেটাডেটা) |
| RAM | mmap (Linux/macOS) / VirtualAlloc (Windows) |
| VRAM | CUDA + NVML (স্টাব, ইন্টিগ্রেশনের জন্য প্রস্তুত) |
