# ডেভেলপমেন্ট গাইড

## কোড স্ট্যান্ডার্ড

- **Go**: [Go Code Review Comments](https://go.dev/wiki/CodeReviewComments) অনুসরণ করুন
- **TypeScript/React**: ESLint প্রস্তাবিত কনফিগারেশন অনুসরণ করুন
- Go কোড ফরম্যাটিংয়ের জন্য `gofmt` ব্যবহার করুন
- ফ্রন্টএন্ড কোড ফরম্যাটিংয়ের জন্য `prettier` ব্যবহার করুন

## কনকারেন্সি নিরাপত্তা

- রিড-হেভি দৃশ্যের জন্য `sync.RWMutex` ব্যবহার করুন
- ডেডলক প্রতিরোধে সর্বদা একই ক্রমে লক অর্জন করুন
- লক রিলিজ করতে `defer` ব্যবহার করুন
- লক ধরে থাকাকালীন বাহ্যিক ইন্টারফেস কল করা এড়িয়ে চলুন

type AppError struct {

## টেস্টিং

- কোর মডিউলের জন্য ইউনিট টেস্ট কভারেজ কমপক্ষে 80% হওয়া উচিত
- API লেয়ারের জন্য ইন্টিগ্রেশন টেস্ট প্রয়োজন
- `testing` স্ট্যান্ডার্ড লাইব্রেরি ব্যবহার করুন

## CI/CD

প্রকল্পটি CI/CD-র জন্য GitHub Actions ব্যবহার করে:

- **ব্যাকএন্ড CI**: push/PR এ বিল্ড, টেস্ট এবং ভেট
- **ফ্রন্টএন্ড CI**: TypeScript চেক এবং বিল্ড
- **ডক্স CI**: VitePress বিল্ড এবং GitHub Pages এ ডিপ্লয়

বিস্তারিত জানতে [CI/CD কনফিগারেশন](/development/ci-cd) দেখুন।
