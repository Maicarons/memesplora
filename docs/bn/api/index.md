# API রেফারেন্স

Memesplora তিনটি অ্যাক্সেস প্রোটোকল প্রদান করে:

## REST API

ফাইল ম্যানেজমেন্ট, স্পেস ম্যানেজমেন্ট, ইউজার অথেনটিকেশন এবং শেয়ারিংয়ের জন্য সম্পূর্ণ HTTP API।

- **পোর্ট**: 5212
- **বেস URL**: `http://localhost:5212/api/v3`
- **Auth**: JWT Bearer Token
- **ডক্স**: [REST API রেফারেন্স](/api/rest)

## S3-সামঞ্জস্যপূর্ণ API

rclone, AWS CLI, MinIO ক্লায়েন্ট এবং অন্যান্য S3 টুলের সাথে ব্যবহারের জন্য AWS S3-সামঞ্জস্যপূর্ণ প্রোটোকল।

- **পোর্ট**: 5213
- **Auth**: AWS Signature V4
- **ডক্স**: [S3 API রেফারেন্স](/api/s3)

## WebDAV

অপারেটিং সিস্টেম ফাইল ম্যানেজারে নেটওয়ার্ক ড্রাইভ হিসেবে মাউন্ট করার জন্য WebDAV প্রোটোকল।

- **পোর্ট**: 5214
- **Auth**: HTTP বেসিক Auth
- **ডক্স**: [WebDAV রেফারেন্স](/api/webdav)
