# কন্ট্রিবিউটিং

## কোড স্টাইল

- **Go**: [Go Code Review Comments](https://go.dev/wiki/CodeReviewComments) অনুসরণ করুন
- **TypeScript/React**: ESLint নিয়ম অনুসরণ করুন
- ফরম্যাটিংয়ের জন্য `gofmt` এবং `prettier` ব্যবহার করুন

## কমিট মেসেজ ফরম্যাট

```
<type>(<scope>): <subject>

<body>
```

টাইপসমূহ: `feat`, `fix`, `docs`, `style`, `refactor`, `test`, `chore`

## ব্রাঞ্চ স্ট্র্যাটেজি

- `main`: স্থিতিশীল রিলিজ
- `develop`: ডেভেলপমেন্ট ব্রাঞ্চ
- `feature/*`: ফিচার ব্রাঞ্চ
- `fix/*`: বাগ ফিক্স

## পুল রিকোয়েস্ট প্রক্রিয়া

1. রিপোজিটরি ফর্ক করুন
2. একটি ফিচার ব্রাঞ্চ তৈরি করুন: `git checkout -b feature/your-feature`
3. আপনার পরিবর্তন কমিট করুন
4. টেস্ট চালান: `make test`
5. একটি পুল রিকোয়েস্ট তৈরি করুন

## কোড রিভিউ

সব PR-এর জন্য কমপক্ষে একজন মেইনটেইনার রিভিউ প্রয়োজন। ফোকাস এলাকা:
- মেমোরি নিরাপত্তা
- কনকারেন্সি নিরাপত্তা (লক সঠিকতা)
- এরর হ্যান্ডলিং সম্পূর্ণতা
- API সামঞ্জস্যতা
