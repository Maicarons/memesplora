# Руководство по разработке

## Стандарты кода

- **Go**: Следуйте [Go Code Review Comments](https://go.dev/wiki/CodeReviewComments)
- **TypeScript/React**: Следуйте рекомендованной конфигурации ESLint
- Используйте `gofmt` для форматирования Go-кода
- Используйте `prettier` для форматирования кода фронтенда

## Безопасность конкурентного доступа

- Используйте `sync.RWMutex` для сценариев с преобладанием чтения
- Всегда захватывайте блокировки в одном и том же порядке для предотвращения взаимоблокировок
- Используйте `defer` для освобождения блокировок
- Избегайте вызова внешних интерфейсов при удержании блокировок

## Обработка ошибок

```go
type AppError struct {
    Code    int    `json:"code"`
    Message string `json:"message"`
}
```

## Тестирование

- Покрытие модульными тестами должно быть не менее 80% для основных модулей
- Слой API требует интеграционных тестов
- Используйте стандартную библиотеку `testing`

## CI/CD

Проект использует GitHub Actions для CI/CD:

- **Backend CI**: Сборка, тестирование и проверка при push/PR
- **Frontend CI**: Проверка TypeScript и сборка
- **Docs CI**: Сборка и развёртывание VitePress на GitHub Pages

См. [Конфигурация CI/CD](/ru/development/ci-cd) для получения подробной информации.
