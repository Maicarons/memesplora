# Справочник API

Memesplora предоставляет три протокола доступа:

## REST API

Полноценный HTTP API для управления файлами, пространствами, аутентификацией пользователей и публикациями.

- **Порт**: 5212
- **Base URL**: `http://localhost:5212/api/v3`
- **Аутентификация**: JWT Bearer Token
- **Документация**: [REST API Reference](/ru/api/rest)

## S3-совместимый API

Протокол, совместимый с AWS S3, для использования с rclone, AWS CLI, MinIO Client и другими S3-инструментами.

- **Порт**: 5213
- **Аутентификация**: AWS Signature V4
- **Документация**: [S3 API Reference](/ru/api/s3)

## WebDAV

Протокол WebDAV для монтирования в качестве сетевого диска в файловых менеджерах операционных систем.

- **Порт**: 5214
- **Аутентификация**: HTTP Basic Auth
- **Документация**: [WebDAV Reference](/ru/api/webdav)
